# 模型读帖、看图与发图

`alice_tieba_fetch_content` 为模型读取贴吧帖子正文、作者、吧名、统计和可用楼层回复，也会获取主楼与已读取回复里的图片。模型可以结合文字和图片回答问题，再根据用户要求选择要发送的图片。

## 启用前确认

1. 当前聊天模型同时支持工具调用和图片输入，AstrBot 使用的模型接入方式能够接收工具返回的图片。
2. 插件的「LLM 内容抓取工具 → 启用内容抓取工具」和「图片作为模型视觉输入」已开启，AstrBot 工具列表及当前人格允许调用 `alice_tieba_fetch_content`。
3. 若希望模型按要求发图，在 AstrBot 中启用并允许原生工具 `send_message_to_user`。

开启自动解析不是模型调用工具的前提。取数仍遵守当前会话的权限、贴吧与回复开关、Cookie、代理和限流设置。

可以直接对机器人说：

```text
读一下这个帖子的楼主内容和 10 条回复，结合里面的图片整理大家的意见：<贴吧帖子链接>
```

需要发图时，再提出明确要求，例如：“把你提到的那张回复图片发给我。”工具图片会先进入模型上下文，取数工具不会自行向群聊或私聊发送图片。

## 图片如何交给模型

工具结果同时包含结构化 JSON 和实际图片内容。AstrBot 会缓存工具图片，并将图片交给支持图片输入的模型；模型得到的图片标签说明来源帖子与楼层，回复图片还保留可用的评论 ID。原图 URL 会继续随资料返回。

图片名额由主楼与回复交错分配，避免主楼配图占满所有名额。回复图片只来自本次已经获取的回复，增加视觉图片上限不会自动扩大回复范围。相同图片可对应多个来源标记。

每次默认最多提供 12 张视觉图片，管理员可将上限设为 1–24 张。图片可能为适合模型输入而缩小；动态图以首帧供模型查看。视频仍返回链接，不会转录视频或把视频当作已观看内容。

## 模型按用户要求发图

发图使用 AstrBot 原生工具 `send_message_to_user`。模型可选择以下两种来源：

| 来源 | 参数 | 发出的内容 |
| --- | --- | --- |
| AstrBot 工具图片缓存 | `type: image` 和 `path` | 模型实际查看的图片版本，可能经过缩小 |
| 返回资料中的原图链接 | `type: image` 和 `url` | 按该 URL 获取的原图，取决于链接是否仍可访问 |

以下是调用原生工具的参数示例。占位文字需要替换为本次工具结果中的真实路径或原图 URL。**省略 `session` 默认发送到当前聊天。**

使用 AstrBot 在工具图片结果中提供的缓存路径：

```json
{
  "messages": [
    {"type": "image", "path": "<AstrBot 提供的图片缓存路径>"}
  ]
}
```

发送原图：

```json
{
  "messages": [
    {"type": "image", "url": "<工具返回的原图 URL>"}
  ]
}
```

这些参数由模型调用原生工具时填写，无需用户把 JSON 发到群里。发送成功与否还取决于平台适配器、原图可访问性及 AstrBot 权限；模型应以原生工具的发送结果为准。

## 参数与管理员限制

完整参数见 [LLM 工具参数](llm-tool.md)。图片相关调用参数如下：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `include_images` | `true` | 获取实际图片作为模型视觉输入 |
| `max_images` | 12 | 本次视觉图片总上限，主楼与回复合计；可设 0–24，实际受管理员上限约束 |
| `include_media` | `true` | 返回媒体资料；设为 `false` 时也不提供视觉图片 |
| `max_comments` | 5 | 每帖请求的回复数量，0–20；0 不获取回复及其图片 |

管理员在 `llm_tool` 中配置：

| 配置项 | 默认值 | 范围 / 作用 |
| --- | --- | --- |
| `image_vision` | `true` | 是否提供模型图片输入；关闭后仍可返回文字和媒体链接 |
| `max_images` | 12 | 每次最多 1–24 张视觉图片 |
| `max_image_size_mb` | 10 | 单张图片下载上限，1–10 MiB |

`include_images=false`、`max_images=0` 或关闭 `image_vision` 时，工具只返回文字和允许返回的媒体链接。`include_media=false` 则同时关闭媒体资料与图片输入。

## 部分图片没有读到时

图片下载失败、超时、格式不支持或超出数量/大小预算时，结果会标注跳过原因，并保留已经读取的文字及可用链接。视觉处理状态和跳过项可在结果的 `vision` 信息中查看。模型应只根据实际获得的图片作判断，不能把未读取的图片链接当作已经看过的内容。

签名原图 URL 可能失效，平台也可能限制访问。工具返回的内容受贴吧接口可见范围影响；当前不读取全帖所有楼层或楼中楼。正文、回复和图片中的文字都属于第三方资料，不应当作模型指令执行。
