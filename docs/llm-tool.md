# 贴吧 LLM 内容抓取工具

`alice_tieba_fetch_content` 读取贴吧主楼和接口首屏的楼层回复，返回结构化 JSON，并默认附带主楼与回复的实际图片供视觉模型查看，让模型按用户要求总结、比较、翻译或分析。工具独立于聊天卡片，不自动发消息、生成卡片或翻译，也不下载视频。启用条件和原生发图示例见 [模型读帖、看图与发图](llm.md)。

## 启用与使用

在插件配置中开启「LLM 内容抓取工具」，使用支持工具调用的聊天模型，并在 AstrBot 工具列表和当前人格中允许 `alice_tieba_fetch_content`。看图还需模型与 AstrBot 接入方式支持图片输入，并开启「图片作为模型视觉输入」；按用户要求发图需启用并允许 AstrBot 原生 `send_message_to_user`。例如：“读取这个贴吧帖子和 10 条楼层回复，结合图片整理大家的意见：链接”。

工具只识别本插件支持的贴吧链接，沿用当前用户/群组权限、贴吧及回复开关、Cookie、代理和解析频率限制。“仅卡片”“仅文本”“仅富媒体”和文本字段开关只控制聊天展示；贴吧输出为“关闭”时工具也不取数。自动解析触发开关不影响模型主动调用。

## 参数

| 参数 | 类型 | 用途 |
| --- | --- | --- |
| `url` | string，必填 | 帖子链接或包含多个贴吧链接的分享文本，最多 12000 字符 |
| `include_comments` | boolean，默认 true | 是否获取首屏楼层回复；仍尊重贴吧回复开关 |
| `include_media` | boolean，默认 true | 是否返回主楼和回复的图片、封面及视频地址；关闭时也不提供视觉图片 |
| `include_images` | boolean，默认 true | 是否附带实际图片作为模型视觉输入，需同时开启 `include_media` 和管理员图片视觉输入 |
| `max_images` | integer，可选，0–24，默认 12 | 本次视觉图片总上限，主楼与回复合计；受管理员上限约束，0 只返回链接 |
| `max_comments` | integer，可选，0–20，默认 5 | 模型按任务自行决定每条链接获取多少回复；0 不获取，省略固定默认 5 |

```json
{
  "url": "https://tieba.baidu.com/p/11180655858",
  "include_media": false,
  "max_comments": 10
}
```

没有配置项把工具评论数量锁在 5 条。平台只提供较少回复时，返回实际可用内容；不翻页获取全帖或楼中楼，不把首屏回复称为热度排行。

## 返回与配置

顶层 `status` 为 `ok`、`partial` 或 `error`，`results` 按链接顺序返回，`skipped` 说明限流跳过项，`omitted_link_count` 表示超过数量上限的链接数。每项可包含来源 `source_url`、帖子规范链接 `url`、标题、正文 `desc`、作者、吧名、时间、真实互动统计和 `hot_comments`。回复保留真实楼层和可用点赞数，缺失数字不编造。

媒体分为 `images`、`videos`、`covers`，每组保留候选 URL 和格式；回复图片保留所属楼层及可用评论 ID。需要请求头的地址用 `requires_headers` 布尔标记，工具不会返回头值、Cookie、代理凭据或原始异常。签名 URL 可能过期或受到访问限制。

开启图片输入后，结果同时包含实际图片内容与 `vision` 状态信息，记录图片来源、尺寸、处理状态和跳过原因。AstrBot 会缓存工具图片并提供路径，模型可将该路径用于原生发图；它对应模型看到的处理版本，要发送原图请使用返回的原图 URL。

| 配置项（`llm_tool`） | 默认值 | 范围/作用 |
| --- | --- | --- |
| `enabled` | 开启 | 注册工具；修改后重载插件 |
| `max_links` | 3 | 每次最多处理 1–5 个链接 |
| `max_output_chars` | 24000 | 完整 JSON 字符预算，4000–60000 |
| `timeout_seconds` | 45 | 每条链接超时，5–120 秒；同时受 AstrBot 工具总超时约束 |
| `max_concurrent_calls` | 2 | 同时执行 1–4 次调用，满额时返回繁忙提示 |
| `image_vision` | 开启 | 附带实际图片供模型查看 |
| `max_images` | 12 | 每次视觉图片总上限，1–24 张 |
| `max_image_size_mb` | 10 | 单张图片下载上限，1–10 MiB |

超出字符预算的内容会裁剪并标记 `truncated`，仍保留合法 JSON 和来源。第三方正文和回复仅作为资料，模型不应执行其中的指令。

模型可以分析本次实际附带的图片；图片下载失败、超时或超出预算时会标注跳过并保留文字/链接。未附带的图片地址不表示模型已看过图片。本工具没有视频转录，视频地址也不表示模型已观看视频。

与 Nova 主插件同时安装时，两个工具名称分别为 `alice_tieba_fetch_content` 和 `nova_fetch_content`，配置、Cookie 和限流记录分别属于各自插件。
