# WebUI 使用说明

WebUI 是本插件的管理页面，复用 AstrBot 的登录与插件页面机制，不需要单独开端口或设置另一套密码。

## 打开页面

在 AstrBot「插件管理」中找到 **爱丽丝的贴吧工具**，打开插件页面 **alice-tieba**。建议从 AstrBot 内打开，以便页面获得正确的登录上下文。

需要 AstrBot `>=4.25.0,<5`。较新的版本可能将「插件页面」称为「插件视图」，入口仍位于插件管理中。如果没有出现入口，先重载插件并刷新 AstrBot 页面，检查插件是否成功加载。

## 页面功能

| 页面 | 可以做什么 |
| --- | --- |
| 概览 | 查看订阅数量、启用状态和近期运行情况 |
| 订阅 | 新增关注/追踪，编辑备注、关键词与推送会话，暂停、恢复、删除、手动检查 |
| 配置 | 按功能分组调整全部配置，搜索字段，保存修改 |
| 运行活动 | 查看最近的监控记录，定位首次基线、检查结果和发送失败 |

媒体缓存清理会处理本插件拥有的媒体缓存，不应被用作删除订阅的方法；有媒体正在处理时，需要等待完成后再清理。

## 设置推送会话

先在需要接收消息的群聊或私聊中发送：

```text
贴吧 会话
```

将机器人返回的完整会话标识复制到订阅表单。这个标识包含平台和会话类型，不能替换为单独的群号或用户号。机器人必须已接入相应平台，且对目标会话具有发送权限。

关注用户可填写数字贴吧 UID，或该用户发布的一个帖子链接，插件会识别楼主并保存用户订阅；追踪楼主填写帖子链接或数字帖号。全局推送关闭时可以管理订阅，但不会检查与发送；新建订阅第一次成功检查只记录基线。

## 四套主题

| 主题 | 配色 |
| --- | --- |
| 月光 | 雾蓝与浅色面板 |
| 曜夜 | 深海蓝与暗色面板 |
| 樱雾 | 玫瑰紫与浅色面板 |
| 森林 | 苔绿与暖白面板 |

主题只改变管理页面外观。聊天里生成的内容卡片，在配置的「卡片渲染」中单独选择深浅配色、布局和皮肤。

## 设置聊天卡片与 QQ 官方 Bot 图片发送

在「配置」页的消息输出设置中，找到「卡片渲染」。默认「卡片风格」为 **贴吧帖子**，按贴吧帖子阅读页组织吧名、作者、正文、大图与楼层回复；深浅配色默认是浅色，也可改成深色。选择管理页面的月光或曜夜主题，不会改变聊天卡片的配色。

QQ 官方 Bot 原图图库默认开启。在群聊与私聊中，插件先单独发送卡片，再将该帖原图放在第二条原生 Markdown 图库消息中，每张图都可以独立点击查看；视频单独发送。希望每张图分别占一条消息时，关闭消息输出中的 QQ 官方 Bot 原图图库设置。图库发送失败时会回退为逐图发送；QQ 频道暂时逐图发送。

这个开关只影响 QQ 官方 Bot，OneBot 和其他平台保持各自原有行为。QQ 官方 Bot 的聚合模式会自动改为普通消息逐帖发送，无法生成 OneBot 式合并转发；一次解析多个帖子时，各自发送图库。详见 [卡片样式与平台发送说明](cards.md)。

## 保存配置与秘密字段

修改配置后使用页面的保存操作。订阅操作会直接保存其状态。部分配置影响工具注册或运行资源，页面提示需要重载时，请在 AstrBot 中重载本插件。

Cookie、API Key 和带凭据的地址属于秘密配置，不回显已有值。空白保存表示保留原值；要删除已保存的秘密，请明确使用清空操作。分享截图、配置文件或日志前，确认没有包含账号 Cookie 和密钥。

页面提交参数会由后端校验。出现错误时按提示修改，已有配置不会因为无效输入而被整体覆盖。运行活动用于查看订阅状态；需要更完整的插件加载或媒体问题诊断时，请查看 AstrBot 日志。

## 页面无法连接时

从 AstrBot 插件管理重新进入页面，确认登录仍有效、插件处于启用状态。使用反向代理时，需要正常转发 AstrBot 的插件页面和 API 路径。此页面不需要将额外端口暴露到公网，也不需要向页面填写 AstrBot OpenAPI Key。
